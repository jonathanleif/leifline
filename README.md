# Leifline

The first public homepage for Leifline: independent guidance in points, disputes and unexpected developments.

## Preview locally

Open `index.html` directly, or serve the folder with any static server.

## Publish with GitHub Pages

Upload the contents of this folder to the root of `jonathanleif/leifline`, then enable Pages from the `main` branch in the repository settings.

## Image note

`assets/leifline-operations.png` is the generated launch artwork. It deliberately shows the founder from behind so it can later be replaced with a reference-based Jonathan portrait without changing the page layout.
